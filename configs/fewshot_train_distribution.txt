Here are examples of LilyPond fragments in the requested style. Each example follows the structure used by the training corpus: a metadata header (composer, period, musical form, ensemble, part) in `%% ===` comments, then `\version` / `\language`, then one or more named music assignments. The model must output only LilyPond code in the same shape — no prose, no markdown fences.
